# Deep Material Organizer Skill

一个面向 Codex 的“深度资料整理”Skill。它把课程转写、会议录音、学习笔记和长篇资料整理成适合复习与长期沉淀的结构化笔记。

它不是简单摘要：会按原始顺序保留重要知识点、案例、推导过程和面试表达，同时去掉重复、口水话和无关闲聊，并修正明显的转写错误。

## 适用场景

- 课程或播客录音转写稿
- 会议记录与访谈材料
- 零散学习笔记
- 长文、研究资料与培训材料
- 需要沉淀到个人知识库的原始内容

## 核心原则

1. **尊重原始顺序**：保留讲述与推导的先后关系。
2. **深度整理而非简单压缩**：保留理解和复用所需的细节。
3. **保留高价值内容**：知识点、定义、案例、数据、因果链、限制条件和面试表达。
4. **清理噪音**：删除无信息增量的重复、口头禅、寒暄和跑题内容。
5. **谨慎纠错**：只修正明显转写错误；不确定且影响含义时明确标注。
6. **不擅自补写**：不把模型自己的知识伪装成原文内容。

## 安装

将整个 `deep-material-organizer` 文件夹复制到 Codex 的 Skills 目录：

```bash
mkdir -p ~/.codex/skills
cp -R deep-material-organizer ~/.codex/skills/
```

重新打开 Codex 会话后即可使用。Skill 默认允许根据语义自动触发，也可以显式输入 `$deep-material-organizer`。

## 触发语示例

- 整理这份内容
- 帮我深度整理这份笔记
- 把这段录音转写整理成复习笔记
- 按原始顺序整理这份资料，保留案例和推导
- 去掉口水话，但不要丢掉重要知识点
- 用 `$deep-material-organizer` 整理下面的课程内容

## 使用方式

直接粘贴文本，或在提供文件/录音转写后提出整理要求。例如：

```text
请整理这份课程录音转写：按原始顺序保留知识点、案例、推导和适合面试复述的表达；删除重复与闲聊，修正明显的转写错误。

[粘贴原始材料]
```

你也可以追加具体要求，例如“输出为 Markdown”“最后增加复习清单”“面向 AI 产品经理面试”。用户的明确格式与受众要求优先。
